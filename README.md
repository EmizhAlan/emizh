# emizh

Персональный конструктор сайта на PHP. Владелец редактирует свой сайт через браузер, посетители видят готовые страницы. Весь контент хранится в папке `data/`, логин и пароль — в файле `owner.json` вне корневой директории сайта.

## Возможности

- Редактирование страниц через браузер, без залезания в код
- Содержимое страниц в формате markdown
- Один владелец, логин создаётся один раз
- Контент и владелец независимы: сброс сайта не затрагивает вход
- Папка `data/` — сменный диск: удалил — сайт вернулся к дефолтному
- Работает на стандартном shared-хостинге с PHP 8+

## Требования

- PHP 8.0 или выше
- Apache или эквивалентный сервер с поддержкой PHP
- Права на запись в директорию выше `public_html/` (для `data/` и `owner.json`)

## Установка

1. Склонируй репозиторий:

   ```bash
   git clone git@github.com:EmizhAlan/emizh.git
   cd emizh
   ```

2. Собери папку поставки:

   ```bash
   php tools/make-dist.php
   ```

3. Скопируй **содержимое** `dist/` в `public_html/` на хостинге.

4. Открой сайт в браузере — увидишь дефолтную страницу.

5. Перейди на `/admin`, создай логин и пароль. Файл `owner.json` появится **рядом** с `public_html/`.

## Структура проекта

```
emizh/
├── src/                # исходники приложения
├── defaults/           # эталон дефолтного сайта
├── tools/              # утилита сборки
├── dist/               # результат сборки (не в git)
├── data/               # контент сайта (не в git, создаётся автоматически)
└── owner.json          # логин/пароль (не в git, создаётся при регистрации)
```
