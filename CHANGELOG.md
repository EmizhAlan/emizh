## [Unreleased]

## [0.3.0] — 2026-10-12

### Добавлено
- Полноценная аутентификация владельца через `/admin/`
- Форма регистрации при первом запуске
- Форма входа для последующих сессий
- Панель управления владельца (`dashboard.php`)
- Страница смены пароля (`password.php`)
- Список страниц сайта в панели управления
- Бейдж «главная» у главной страницы
- Форматирование дат («только что», «5 мин назад», «вчера»)
- Класс `Auth` для работы с `owner.json`
- Класс `Csrf` для защиты форм
- Класс `RateLimit` для ограничения попыток входа
- Защита всех админских маршрутов
- Безопасные сессии: `HttpOnly`, `SameSite=Lax`, `Secure` на HTTPS
- Защита от фиксации сессий (`session_regenerate_id`)
- Ротация CSRF-токена каждые 15 минут
- Таймаут сессии через 30 минут неактивности
- Rate limit: 5 попыток входа за 5 минут
- Таймер блокировки в форме входа
- Логирование критических ошибок в `emizh.log`
- Обработка повреждённого `owner.json` с понятным сообщением

### Изменено
- `logout.php` работает только по POST с CSRF-токеном
- `Auth::read()` не бросает исключений — возвращает `null` и логирует

## [0.2.0] — 2026-10-06

### Добавлено
- Каркас проекта и служебные файлы репозитория
- Дефолтный сайт в `src/defaults/`
- Классы `Version`, `Storage`, `Page`, `Site`
- Класс `Markdown` — собственный парсер
- Читательская часть с навигацией и темой
- Скрипт сборки `tools/make-dist.php`
- `.htaccess` для защиты служебных папок

## [0.1.0] — 2026-10-04

### Добавлено
- Первый рабочий каркас
